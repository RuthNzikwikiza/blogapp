# BlogApp

A simple and intuitive web application that allows users to create, read, update, and delete blog posts. Built using Python and Django for the backend, with HTML and CSS for the frontend.

---

## Features
- User authentication (sign up, login, logout)
- CRUD operations for blog posts
- Responsive design for mobile and desktop devices
- User-friendly interface

---

## Technologies Used
- Python
- Django
- HTML5
- CSS3
